## 📦 **To Push to GitHub**

### Step 1: Create Repository on GitHub

1. Go to https://github.com/new
2. Repository name: `AgentTown` (or your choice)
3. Description: `A multi-agent simulation with AI personalities, conversations, and dramatic life/death mechanics`
4. **Make it Public** (for portfolio)
5. **DO NOT** initialize with README, .gitignore, or license (we already have them)
6. Click "Create repository"

### Step 2: Push Your Code

GitHub will show you commands. Use these:

```bash
# Add remote (replace YOUR_USERNAME)
git remote add origin https://github.com/YOUR_USERNAME/AgentTown.git

# Verify remote
git remote -v

# Push to GitHub
git push -u origin main

# Enter your GitHub credentials if prompted
```

### Step 3: Verify

Go to your GitHub repository URL and verify:
- ✅ All files are there
- ✅ README displays properly
- ✅ 11 commits visible
